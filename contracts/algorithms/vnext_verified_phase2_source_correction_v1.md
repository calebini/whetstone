# Verified Phase 2 declaration-stage source correction v1

Internal opt-in extension requiring the verified Phase 2 operator, resolution,
sequence, and declaration contracts. Existing suites retain their exact bytes
and behavior. This contract does not activate public modes.

The ordinary configured final convergence review uses request and consumption
v4. It reviews the immutable current-lineage declaration and source together.
It may admit ordinary in-scope source findings through the existing explicit
advice, operator, candidate, preservation, semantic verification and promotion
owners. Declaration artifacts remain Orchestrator-owned. A source correction
must not absorb declaration, rubric, authority, invariant or mixed findings as
if they were wholly source-resolved. Unsupported or ambiguous findings retain
the declaration reconciliation gate; mechanical declaration validity cannot
override Reviewer disagreement.

The ordinary step budget remains binding. Consuming a review spends one pass;
candidate retries do not add review credit. A source correction on the final
allowed pass may retain its verified result but cannot grant another ordinary
review or convergence. A promoted source correction invalidates profile
cleanliness, publishes existing resolution evidence and requires a new immutable
declaration package before a remaining scheduled convergence review. The new
package uses the promoted pointer and retained unresolved evidence. Earlier
declarations and review artifacts remain immutable.

A scheduled clean declaration review still goes through finding reconciliation,
target evaluation and terminal publication/recovery. Missing current profile
verification stays explicit. This contract alone does not grant optional
review-only closeout, accepted rubric gaps, new targets, version maintenance,
freeze release, external apply-back or any automatic semantic repair.

Historical admission reproduces the source review from its bounded pointer
prefix. Current writes use the D8 fence and source barriers. Recovery reuses
committed requests and results without duplicate client calls or review credit.
