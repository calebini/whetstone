# Verified operator v1 (unactivated)

This consumer extends the fenced live V work owner with exact interpretation answers and explicit child-transaction selection. It requires the live-work, semantic-answer and semantic-follow-up contracts and does not activate a public suite or alter P behavior.

All mutation uses the live owner's fresh lineage proof, ordered materialization/registration/promotion precedence and continuous real fence. New operator work requires the latest registered candidate and its exact current base-pointer reference. A rejected candidate's final decision and outstanding question remain immutable. Interpretation answers add no editing effects, deletion permissions or authority grants.

An answer requires the explicit closed-schema input with exact question and final verification references, selected option or decline, rationale, accountable identity and timestamp. Reuse the existing response binder, canonical identity and response/receipt producer. Inspect existing responses, reject identity conflicts, repeat original source durability barriers, publish the response before its bound receipt, and read back the exact receipt. A response never selects a transaction automatically. Inspection and dry-run perform corresponding validation without repairing or writing.

Child selection takes an explicitly named answer receipt path/hash. Reproduce the actual rejected source, durable Verifier evidence, original round/editing scope and selected interpretation through the V historical reader's strict earlier-source boundary. Derive the distinct v3 plan and canonical admission record. Publish the exact admission before its source-candidate selection marker. Reentry may reuse only identical receipt and admission bytes, preserving the original selection; a different answer cannot refresh the marker. A decline cannot produce child work. New or repeated mutating operator commands may not bypass current candidate/base eligibility; historical answer inspection remains read-only and reports no submission permission for a superseded source.

The shared publication helpers retain the P public wrappers and their P decision readers. The V caller separately supplies a read-only historical router for evidence reproduction and the fenced live admission for source durability writes. Neither historical replay nor an ambient answer grants permission to invoke a client.

Qualification requires an actual semantic question followed by production answer publication, child selection, live child request/registration/verification and promotion; exact parent preservation; independent response/receipt and admission/selection interruption recovery; stale or superseded input refusal; decline and alternate-receipt refusal; no new model calls during operator actions; and unchanged P answer/follow-up behavior. Durable runtime selector persistence, scheduler/phase integration, D8 audit and complete release qualification remain gates before activation.
