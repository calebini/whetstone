# Verified Reviewer requests v1 (unactivated)

This private consuming journal reviews a single already-selected round/profile against an exact proven base pointer. It does not select scheduler work, authorize a new round, clear findings, publish proposal admission, change budgets or declare phase readiness. The bounded historical reader below supplies original journal evidence. The V sequence owner and its work-eligibility validation remain required before exposing live Reviewer commands or accepting feedback into normal V round admission.

The caller supplies only a fresh invocation-local committed-history proof. The base reference must already occur in that proof's acyclic validated set. Preflight rereads bound seed inputs, current/original base bytes and map, and any promoted inventory. The original seed remains unchanged context; the prompt and decoder review the selected base bytes/map/hash, configured Reviewer identity and exact round/profile. Authority and dependency documents retain their declared roles; exclusions are omitted. Advice cannot grant effects or operator decisions.

The new closed `vnext-review-request-v2` header adds an exact base-pointer path/hash to the existing logical request, round/profile, input hash, predecessor-claim hash and transport. Preserve v1 bytes and P defaults. The typed input projection binds both original seed and selected base, pointer reference, suite and full included context. Same-byte promotions at different pointers must remain distinct inputs. Replaying a historical request does not virtualize or replace the actual current pointer.

Reuse the existing durable two-slot transport loop and receipt mechanics through private mode-aware preflight/decoder hooks. Persist the original prompt, invocation prompt/marker, raw output and deterministic outcome; publish feedback/advice before the final result receipt. Shape failure permits only the existing bounded repair. Binding/classification failure is not shape repair. Technical interruption needs explicit continuation and preserves the claimed transport and consumed invocation slots. A retained valid result finishes without a client; completed, invalid or exhausted requests do not invoke again.

Mutation requires the caller's live borrowed fence and exact current base reference. An old base or a read-only history store cannot invoke or publish, even when its evidence is valid. Token ownership and current authority are rechecked; source changes during a client call prevent result commitment. All receipt reentry repeats applicable durability barriers without another client or ordinal.

The bounded historical reader reproduces exact claims 1..N, their predecessor hashes, original base references, prompts, raw responses, decoded feedback/advice and receipts without enumerating future claims. A complete prefix may not contain an incomplete request; full current inspection permits at most a final pending request and refuses gaps or unknown claims. Every original base must already be in the invocation-local validated set. The actual current pointer remains unchanged; returned request handles are read-only and grant no live-work authority.

The eventual sequence owner must additionally validate exact profile/budget selection, phase rules and source-round eligibility. Historical candidate admission must validate only the Reviewer prefix justified by already proven bases; it cannot recursively depend on later promotion history. Until those owners qualify, this journal is an unactivated component and the stored-run runtime-Reviewer guards remain in force.
