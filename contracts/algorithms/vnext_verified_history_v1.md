# Verified history replay v1 (unactivated)

This read-only consumer requires explicit pinned verified-semantic and historical-replay algorithms, their consumed schemas, and the existing proposal and semantic follow-up contracts. It does not activate a shipping suite, admit a model call, acquire a promotion lock, publish artifacts, repair state or advance a pointer.

Every public read begins with fresh descriptor-bound suite/bootstrap and immutable seed validation. The actual current pointer selects the complete structural history through ordinal zero. Neither a caller-supplied history, an unattached snapshot nor a directory timestamp can supply a base. The store's actual current pointer is never substituted with a historical pointer.

The reader proves promotions in increasing ordinal. A proof-local set initially contains only the validated seed. For promotion K, replay the genuine creation prefix through its bound source candidate, resolving each immutable round and proposal transaction against an exact previously proven base reference. Reproduce durable Editor output, handoff, candidate bytes, map, preservation report and inventory. Then reproduce the promoted candidate's independent durable Verifier result and final candidate-local decision, including its exact predecessor and promotion tail. The decision and creation must equal the global pointer's hash-bound targets, and the transaction must use the pointer's exact predecessor base. Only then add the promoted bytes, map and reproduced inventory to the proof-local base set.

Semantic follow-ups retain their explicit transaction selection and exact answer receipt. Resolve their original round base, retain their editing scope, and replay each rejected source through a strictly earlier creation prefix. A source cannot depend on itself or a later candidate. Interpretation answers add no effect grants. The V reader shares existing follow-up reconstruction through a V semantic decision reader; existing P entry points preserve their mode guards.

After proving committed history, replay the full registered candidate chain against the proven bases. Later candidate contents must not participate in proving an ancestor promotion. Registration orphans are reported, never repaired. Recheck the actual current pointer and descriptor at the end and before internal evidence reads. All proof state is local to one public invocation; no cached Python result is an authority grant for a subsequent invocation.

Round-input reconstruction returns its original bound base and inventory, even after the head advances. This is historical evidence access, not permission to run stale work. A later live admission owner must separately select current work under the storage fence, perform both promotion reconciliation stages, and enforce scheduler and recovery gates. Effective promoted disposition comes from proven global history, not a semantic decision view or an unbound prepared event.

Qualification requires genuine one- and multiple-promotion histories, original and same-round follow-up transaction replay, refusal of altered original Editor/Verifier evidence, prevention of future/self-supporting bases, changed-head detection, no writes or client calls, explicit contract refusal and unchanged P/legacy behavior. These checks and D8/release qualification are required before activation.
