# Verified vertical Phase 1 v1 (internal)

Separately pinned extension of the V Reviewer sequence, closeout and operator
projection. Consumes immutable standard vertical review configuration v1 and
fresh runtime roots without staged rounds. Frozen suites and public activation
remain unchanged. Focused configuration v2 does not admit vertical selection.

Reconstruct every cycle from independent original Reviewer claims, responses,
receipts, roles and exact current-base bindings. Review eligible configured
profiles in their immutable order on one pointer. Each completed logical review
consumes that profile's budget once. Retained output and explicit technical
continuation use the existing request-wide two-slot allowance. A timeout cannot
drop earlier cycle findings or replay completed profiles. Source snapshots,
focus anchors, prompt/context snapshots and telemetry remain independent.

When a cycle has feedback, allocate a distinct synthetic `vertical` round after
its source reviews. Merge in profile/round/feedback order without changing issue
IDs or fingerprints. For duplicate source feedback IDs, rewrite all IDs using the
scheduler's profile-slug convention and stable collision suffixes. Bind source
receipts, original feedback/advice, original IDs and profiles in an immutable
merge record; retain that provenance in the consolidated Editor input. Reclassify
all merged findings under unchanged authority: merge grants no permission.
Publish source barriers and exact merged artifacts before the merge commit, then
publish the ordinary packaged proposal input. Partial publication is replayable
only with identical bytes. No independent profile review admits an Editor.

One cycle can advance to a new base only through the immediately next proven
promotion of its synthetic round. Editor claims cannot establish cleanliness.
Every promotion, including equal-byte promotion, invalidates all profile clean
observations. Counts survive. Profiles with remaining capacity run in the next
cycle; exhausted profiles cannot gain implicit capacity. The optional extra
verification-only closeout cycle is not implemented by this pin.

A cycle with only deferable feedback receives an immutable no-op synthetic round;
a feedback-free cycle requires no synthetic round. Complete current-base clean
reviews plus the existing global acceptance checks permit Phase 1 stability.
Otherwise exhaustion reports TARGET_NOT_REACHED and current verification debt.
The total review-round budget is the sum of profile budgets plus their maximum;
profile counters count only independent reviews. Fixed closeout v3 binds the
configuration, all review receipts, merge commits and any technical report.
Repeat source and ownership barriers under D8 before dependent publication and
recovery-only state projection. No clients run during report/state recovery.

No budget-extension events, generic resume, version stamping, source apply-back,
public mode activation, or legacy full-draft execution is added.
