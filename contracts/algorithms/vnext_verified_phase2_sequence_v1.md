# Bounded Phase 2 continuation

Separately pinned, internal standard horizontal continuation. Preserve immutable
first-request artifacts and original-entry Phase 1 prerequisites. Replay subsequent
requests in contiguous pass order; each binds its predecessor consumption, exact
proven base, configuration, transport, round and ordered profile-step identity.
No mutable counters or state fields confer permission. No legacy executor.

Use existing PhaseScheduler profile-step budgets, repeated names and cleanliness
rules. Only validated result receipts count, once each. A correction requires the
next committed promotion from that exact source round before another review. A
clean review followed by a byte-changing correction requires another verification;
promotion clears distinct-profile cleanliness for changed bytes but never budgets.
Stop at exhausted residual budgets, unresolved advice/decisions, rejected work,
oscillation/conflict signals, declaration maintenance and final closeout gates.
End-of-sequence is not convergence or authority to extend budgets.

Historical round replay reads only the bounded original request prefix and proven
predecessor ancestry, with the actual head guard intact. Further editor-fixable
corrections use unchanged packaged constraints and the existing V transaction.
Versioned mutations, operator followups, automatic advice, declarations and public
activation remain unsupported. Never replace Phase 1 or old first-only contracts.

Under D8, repeat exact source and predecessor barriers before publishing a request,
result consumption, advisory attachment or canonical round. Freeze each request's
transport. Reuse the bounded two-attempt client journal and require explicit
technical continuation. Recovery of a retained request/result is a separate call
from selection of a successor. Completed pass replay cannot allocate another pass.
Retain all historical inputs, outputs and evidence across restart and lost write
acknowledgements; pending materialization/registration/promotion has precedence.
