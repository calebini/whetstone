# Verified Phase 2 exact rubric evidence v1

Internal opt-in extension requiring source-correction and verified resolution.
The immutable standard rubric remains authoritative and hash-bound. Reviewer
transport selects the new closed response envelope: existing Phase 2 review
plus exact rubric-finding annotations. It cannot assign accepted/resolved status.

The Orchestrator provides an ordered catalogue of exact nonempty requirement
paragraphs and list items under canonical rubric section anchors. Each entry
binds its complete bytes and position; an annotation selects one exact entry by
anchor and content hash, and a real feedback ID. Rubric-impact findings require
attribution. Missing, duplicate, unknown or mismatched attribution is invalid
Reviewer output, subject only to the existing logical-request retry budget.
Every gap has exactly one requirement, canonical fingerprint/ID and source-order
sorting. Neither a severity label nor free-text reference becomes acceptance.
An unresolved applicable requirement remains blocking even if its associated
source feedback is marked out of scope. It also prevents review-only closeout
eligibility; source scope cannot waive independent rubric debt.

Editor and Verifier contexts embed the same reproduced rubric and attributed
requirements. Ordinary wholly source-scoped gap findings may use existing V
correction admission. Complete verified resolution of the original admitted
finding resolves its attributed gaps. A partial or narrower derived task cannot
clear the original gap. Resolution requires a committed resolution receipt;
later Reviewer silence does not clear debt, recurrence reopens it, and changing
rubric/configuration is not resolution.

The declaration gap artifact retains resolved and unresolved entries. Only
unresolved blocking gaps contribute to declaration counts; final/strict forbids
unresolved or accepted gaps. This contract provides no gap-acceptance decision
owner. All other targets remain governed by separately implemented target
configuration/policy; this pin alone does not qualify their runtime journeys.
Original source findings, invariants and authority gates remain independent.

Raw Reviewer bytes and immutable request/result references own gap provenance.
No mutable attachment can manufacture a gap or resolution. Publication, historical
replay and D8 barriers use the existing request, candidate, resolution and
declaration owners. Frozen suites, public activation and external apply-back
remain unchanged.
