# Status reporting

Use the selected runtime's `status` first and retain diagnostic paths. Summarize
what is happening, current accepted draft/profile/cycle when known, actual
allowances, required decisions and the permitted next action. Do not invent a
new persisted state vocabulary to make the summary simpler.

## Liveness and incomplete output

A saved active record is not proof that a process is alive. Report running only
with current process/launcher evidence; otherwise say liveness is unknown.
Missing feedback during an observed review may be expected. Missing evidence
required by a committed result is different. Do not recommend repair merely
because the latest directory is partial or assume stale active state is healthy.
Use diagnostics and the mode's supported recovery gates to resolve uncertainty.

## Updates

Prefer meaningful operation completions, decisions, failures and outcome changes.
Periodic heartbeats are appropriate when requested, but do not narrate unchanged
polls. Before validation, do not report provisional model text as accepted findings.

An operation-complete digest can include in-scope findings, accepted versus pending
edits, remaining profile allowance and next action. Report client/model, retries,
latency and tokens only where recorded. Round numbers do not measure model calls;
configured Phase 2 defaults do not authorize that phase. Keep hashes and paths in
detailed evidence rather than overwhelm the normal explanation.

## Decisions and completion

For required effects show exact before/after, affected source, meaning, reason and
requested decision. Advisory decision cards need not be blocking gates. No silent
operator attestation, candidate reopening or evidence rebasing is permitted.

At a stop, report the actual terminal/gate, residuals, accepted draft and supported
next step. An audit can succeed with findings; focused stability, Phase 1 stability
and convergence have different meanings. Do not infer resume eligibility from
failure type alone. Preview a supported continuation before executing it, within
actual authority. Source adoption remains separate.
